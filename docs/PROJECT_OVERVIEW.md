# 프로젝트 개요

## 한 줄 요약
멘토링, 스터디, 스터디카페 예약, 화상 스트리밍, 캘린더, AI 챗봇을 하나로 묶은 학습 플랫폼 **EASYS**입니다. 팀원 3명이 만들었습니다.

## 배경과 목적
- 공부에 필요한 활동(배우기, 공간 찾기, 함께 공부하기, 일정 관리)이 서비스마다 흩어져 있다는 문제에서 출발했습니다.
- 예약·결제가 끝나면 일정이 캘린더에 자동으로 들어가게 해서 **신청부터 일정 관리까지 한 흐름**으로 연결하는 것을 목표로 했습니다.
- 처음 온 사용자도 기능을 쉽게 찾도록 AI 챗봇이 기능을 안내하고 해당 화면으로 이동시켜 줍니다.
