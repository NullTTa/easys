# 프로젝트 개요

## 왜 만들었나
공부하려면 멘토를 찾는 곳, 공부할 공간을 예약하는 곳, 함께 공부하는 곳, 일정을 관리하는 곳이 모두 따로 있습니다. EASYS는 이것들을 한 서비스에 모으고, **예약하고 결제하면 일정이 캘린더에 자동으로 들어가도록** 연결하는 것을 목표로 만들었습니다.

처음 온 사람도 기능을 쉽게 찾을 수 있도록 AI 챗봇을 넣었습니다.

## 내가 맡은 일
- **디자인·UI:** 서비스 전체 디자인과 공통 화면. 메인, 캘린더, 멘토링, 결제, 챗봇 화면 구현
- **AI 챗봇:** Gemini에서 로컬 AI(Ollama `qwen2.5:3b`)로 전환, 질문 분류, 대화 기억, 페이지 이동 버튼
- **캘린더 연동:** 개인 캘린더, 멘토링 결제 후 일정 저장, 스터디카페 예약 확정 시 일정 저장, 방송방 미니 캘린더
- **멘토링:** 멘토 등록, 신청·승인·거절·완료, 결제, 1:1 채팅, 멘토링 알림, 후기

팀원과 나눠서 한 부분은 [README](../README.md#팀원과-나눠서-한-부분)에 적었습니다.
